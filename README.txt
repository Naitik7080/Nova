NOVA Studio multi-page frontend demo
=====================================

Pages:
- index.html    Home
- services.html Services
- work.html     Portfolio / selected concept work
- about.html    About the studio
- contact.html  Contact form

Shared files:
- style.css
- script.js

Run locally:
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. All pages link to each other through the top navigation.

Important:
- This is a frontend-only demo. The contact form validates fields and opens a prefilled email draft; it does not send or store data automatically.
- Replace hello@yourcompany.com in contact.html and script.js with your actual email.
- Portfolio entries are illustrative concept work, not real client projects.
- Google Fonts require an internet connection; fallback fonts are included.
